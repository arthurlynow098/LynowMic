# Lynow Mic

Use o microfone do seu celular Android no Windows pela rede local.

O projeto inclui:

- aplicativo Windows em WPF/C#;
- aplicativo Android em Kotlin;
- pareamento por QR Code;
- transmissão PCM mono em 48 kHz/16-bit;
- conexão TLS com certificado validado pelo pareamento;
- site, documentação e código-fonte.

## Downloads

Os binários não ficam no histórico do Git porque o executável portátil inclui o runtime .NET e ultrapassa o limite comum de arquivos do GitHub.

Baixe o Windows e o APK Android em [Releases](https://github.com/arthurlynow098/LynowMic/releases/latest).
